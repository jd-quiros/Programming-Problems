# Programming Problems

Archivo personal de programación: soluciones propias a problemas de distintas plataformas y a la lista de los 99 Problems.

- **99-problems** está separado por lenguaje, porque los mismos problemas se pueden resolver en varios lenguajes y cada uno tiene su propia configuración.
- **Las plataformas** usan una carpeta plana. El lenguaje lo indica la extensión del archivo.


Nombres en minúsculas y separados por guiones. Al inicio de cada archivo, un comentario con el enlace al enunciado.


Enunciados: [Ninety-Nine Kotlin Problems](https://github.com/dkandalov/kotlin-99).
