# Programming Problems

Archivo personal de programación competitiva: soluciones propias a problemas de distintas plataformas y a la lista de los 99 Problems.

## Estructura

```
99-problems/
  kotlin/          proyecto Gradle, una carpeta por sección
codeforces/
codechef/
leetcode/
omegaup/
beecrowd/
```

- **99-problems** está separado por lenguaje, porque los mismos problemas se pueden resolver en varios lenguajes y cada uno tiene su propia configuración.
- **Las plataformas** usan una carpeta plana. El lenguaje lo indica la extensión del archivo.

## Convención de nombres

| Carpeta | Formato | Ejemplo |
|---|---|---|
| 99-problems | `PNN.kt` dentro de su sección | `99-problems/kotlin/lists/P01.kt` |
| codeforces | `<contest><letra>-<nombre>.<ext>` | `1520A-do-not-be-distracted.kt` |
| codechef | `<codigo>-<nombre>.<ext>` | `FLOW001-add-two-numbers.c` |
| leetcode | `<numero>-<nombre>.<ext>` | `0070-climbing-stairs.c` |
| omegaup | `<alias>.<ext>` | `sumas.c` |
| beecrowd | `<numero>-<nombre>.<ext>` | `1001-extremely-basic.c` |

Nombres en minúsculas y separados por guiones. Al inicio de cada archivo, un comentario con el enlace al enunciado.
